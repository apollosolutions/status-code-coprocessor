The following project is a coprocessor demo working with the Router

To get it up and running please do the following

Note: There is 



1. Install the router in the root directory
```bash
npm run router:install
````

2. Start the co-processor in the coprocessor directory
```bash
npm start
```

3. Start the subgraph in the subgraph-user directory
```bash
npm run dev
```

4. Start the router at the root directory - NOTE you have copied the required keys into the package.json
```bash
npm run router
```
